#+title: chezmoi-mode

~chezmoi-mode~ provides Emacs commands for editing and synchronizing files
managed by [[https://chezmoi.io/][chezmoi]].  It works with chezmoi's source and target states,
and includes support for templates, Dired, Ediff, Magit, and Transient.

[[https://melpa.org/#/chezmoi-mode][file:https://melpa.org/packages/chezmoi-mode-badge.svg]]

[[file:resources/chezmoi-template-recording.gif]]

The recording shows a chezmoi template source file on the left, the command
log on the top right, and the rendered target file on the bottom right.

* Installation

  Install the package from the Git repository with ~use-package~ and its
  ~:vc~ keyword.  The Dired, Ediff, Magit, and Transient integrations are
  included in the main package and load only when used.

  #+begin_src emacs-lisp
(use-package chezmoi-mode
  :vc (:url "https://github.com/cat-emacs/chezmoi-mode"
       :rev :newest))
  #+end_src

  The optional Age integration is packaged separately in the same repository:

  #+begin_src emacs-lisp
(use-package chezmoi-age
  :vc (:url "https://github.com/cat-emacs/chezmoi-mode"
       :lisp-dir "extensions/chezmoi-age"
       :rev :newest)
  :autoload (chezmoi-age-get-identity chezmoi-age-get-recipients))
  #+end_src

  ~chezmoi~ must be installed and configured.  Template display and
  completion additionally require a Go Template Tree-sitter parser.  The
  package can use a mode selected by ~chezmoi-template-mode-hook~, such as
  ~go-template-ts-mode~, for source files ending in ~.tmpl~, beginning with
  ~modify_~, or located below ~.chezmoitemplates~.

* Quick start

  ~chezmoi-find~ selects a managed target file, opens its source file, and
  enables ~chezmoi-mode~.  If the source and target are synchronized when the
  source is opened, saving the source automatically applies it to the target.

  #+begin_src emacs-lisp
(global-set-key (kbd "C-c C f") #'chezmoi-find)
(global-set-key (kbd "C-c C s") #'chezmoi-write)
  #+end_src

  You can also enable or disable the minor mode with ~M-x chezmoi-mode~.
  Visiting a file below ~chezmoi-root~ enables it automatically, except for
  data files below ~.chezmoidata/~ or files named ~.chezmoidata.*~.  Set
  ~chezmoi-auto-enable-mode~ to nil to disable automatic activation.

  For a menu of the common commands, run ~M-x chezmoi-transient~.

* Source and target states

  Chezmoi stores a source state and applies it to a target file.  The main
  commands for moving between these states are:

  | Command                 | Description                                      |
  |-------------------------+--------------------------------------------------|
  | ~chezmoi-find~           | Open the source for a managed target file.       |
  | ~chezmoi-write~          | Apply source to target, or copy target to source. |
  | ~chezmoi-sync-files~     | Interactively sync multiple changed files.      |
  | ~chezmoi-open-other~     | Open the corresponding source or target file.   |
  | ~chezmoi-diff~           | Show the output of ~chezmoi diff~.               |
  | ~chezmoi-ediff~          | Compare and resolve source and target states.   |
  | ~chezmoi-merge~          | Run chezmoi's configured external merge tool.   |

  When called in a target buffer, ~chezmoi-write~ copies the target contents
  into the source buffer without saving it.  Call it with a prefix argument to
  save that source buffer.  When called in a source buffer, it applies the
  source to the target; a prefix argument passes ~--force~ to chezmoi.

  The commands ~chezmoi-find-data~, ~chezmoi-find-externals~,
  ~chezmoi-find-scripts~, ~chezmoi-find-templates~, and
  ~chezmoi-find-special-file~ select files from chezmoi's special source
  directories and files.  ~chezmoi-find-scripts~ uses the same source-opening
  path as ~chezmoi-find~, so template mode selection and synchronization are
  initialized for Chezmoi scripts as well.

  The following table summarizes the closest chezmoi and Emacs equivalents:

  | Emacs command | chezmoi command | chezmoi-mode command |
  |---------------+-----------------+----------------------|
  | ~find-file~   | ~chezmoi edit~  | ~chezmoi-find~       |
  | ~save-buffer~ | ~chezmoi apply~ | ~chezmoi-write~      |
  | ~diff~        | ~chezmoi diff~  | ~chezmoi-diff~       |
  | ~ediff~       | ~chezmoi merge~ | ~chezmoi-ediff~      |
  | ~magit-status~| ~git status~    | ~chezmoi-magit-status~ |

* Templates

  For template source buffers, ~chezmoi-mode~ displays the values of
  [[https://www.chezmoi.io/user-guide/templating/][chezmoi template]] selectors
  using text properties.  It also provides completion through Emacs'
  standard completion-at-point protocol when a ~gotmpl~ Tree-sitter parser is
  available.

  Toggle displayed values with ~M-x chezmoi-template-buffer-display~, or set
  the default with:

  #+begin_src emacs-lisp
(setq-default chezmoi-template-display-p t)   ; Display values by default.
(setq-default chezmoi-template-display-p nil) ; Keep template expressions visible.
  #+end_src

  ~chezmoi-template-display-p~ can also be made buffer-local with ~setq~.  The
  ~chezmoi-template-mode-hook~ hook can select the major mode used for a
  template source.  The public function
  ~chezmoi-template-normalize-host-filename~ removes chezmoi source
  attributes when another integration needs to infer a host mode from a
  filename.

* Integrations

  ** Transient

     ~M-x chezmoi-transient~ opens a menu for finding files, applying and
     syncing changes, inspecting status and configuration, resolving
     conflicts, and controlling the current buffer.  Its ~-f~ infix forces an
     apply or saves an updated source buffer while syncing.

  ** Dired

     In a Dired buffer, mark files and call
     ~chezmoi-dired-add-marked-files~ to add them to chezmoi.

  ** Ediff

     Use ~chezmoi-ediff~ to compare source and target states, or
     ~chezmoi-ediff-merge~ to include the common ancestor when resolving a
     conflict.  Use ~chezmoi-diff~ when a raw diff buffer is sufficient.

  ** Magit

     ~chezmoi-magit-status~ opens Magit for the chezmoi source repository.

  ** Evil and ligatures

     Template display can be toggled while entering and leaving Evil insert
     state.  Overlaid template values may also render poorly with ligatures;
     the following hook disables them in chezmoi buffers:

     #+begin_src emacs-lisp
(defun my-chezmoi-evil-template-display ()
  (if (eq evil-state 'insert)
      (chezmoi-template-buffer-display nil (point))
    (chezmoi-template-buffer-display t)))
(add-hook 'evil-normal-state-entry-hook #'my-chezmoi-evil-template-display)
(add-hook 'evil-insert-state-entry-hook #'my-chezmoi-evil-template-display)

(with-eval-after-load 'ligature
  (add-hook 'chezmoi-mode-hook
            (lambda () (ligature-mode (if chezmoi-mode 0 1)))))
     #+end_src

  ** Org Babel

     To apply a tangled source file after Org Babel finishes, add
     ~chezmoi-write~ to ~org-babel-post-tangle-hook~:

     #+begin_src emacs-lisp
(add-hook 'org-babel-post-tangle-hook #'chezmoi-write)
     #+end_src

* Configuration

  The most useful options are:

  | Option                             | Purpose                                      |
  |------------------------------------+----------------------------------------------|
  | ~chezmoi-command~                  | Path or name of the chezmoi executable.      |
  | ~chezmoi-root~                     | Chezmoi source directory.                    |
  | ~chezmoi-auto-enable-mode~         | Automatically enable mode under the root.    |
  | ~chezmoi-mode-overwrite-destination~ | Always allow saves to overwrite the target. |
  | ~chezmoi-template-display-p~       | Display rendered template values.            |
  | ~chezmoi-template-display-delay~   | Idle delay before refreshing displayed values. |
  | ~chezmoi-template-completion-cache-duration~ | Template data cache duration. |

  Customize these variables with ~M-x customize-group RET chezmoi-mode-settings~.

* Development

  Install the test dependencies and run the checks with:

  #+begin_src shell
make install-test-deps
make clean all
make compile-age
  #+end_src

  ~compile-age~ additionally checks the independently packaged Age
  integration.
